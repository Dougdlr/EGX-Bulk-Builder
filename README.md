# EGX Bulk Builder

Ferramenta local para criação, organização, validação e edição em massa de campanhas e anúncios.

## Versão-base

- **Versão:** V13.10
- **Tipo atual:** aplicação HTML local
- **Arquivo principal:** `app/EGX_Bulk_Builder.html`

## Como executar

1. Baixe ou clone este repositório.
2. Abra `app/EGX_Bulk_Builder.html` em um navegador compatível.
3. Para recursos que dependam de APIs do navegador, prefira executar em um ambiente local apropriado (por exemplo, localhost) em vez de abrir diretamente via `file://`.

## Estrutura

- `app/`: aplicação principal.
- `docs/`: documentação, arquitetura e roadmap.
- `releases/`: notas e materiais de versões estáveis.

## Desenvolvimento

O projeto está em desenvolvimento ativo. Consulte `CHANGELOG.md` para registrar mudanças e use commits pequenos e descritivos.

## Dados e privacidade

Não envie para este repositório dados pessoais, listas reais de campanhas, arquivos de clientes, pastas de projetos, tokens, credenciais ou dados de uso. O repositório deve conter código e documentação do software.
